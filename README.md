# F4 COOP — тестовые сборки / test builds

Здесь лежат **только готовые сборки** кооператива для Fallout 4 — для тестеров. Исходного кода здесь нет.

**Как поставить**
1. Нужны: Fallout 4 из Steam версии 1.11.240, [F4SE](https://f4se.silverlock.org/) 0.7.9 и [Address Library](https://www.nexusmods.com/fallout4/mods/47327).
2. В разделе **Releases** справа скачать `F4CoopLauncher.exe` из последнего релиза.
3. Запустить его, нажать «Обновить», потом «Играть».
   Windows может предупредить «Windows защитила компьютер»: нажать «Подробнее» → «Выполнить в любом случае» (у программы пока нет платной подписи кода).

Лаунчер проверяет подпись каждой сборки и не ставит файлы, которые подменили по дороге.

**Лицензия.** Мод распространяется под GPL-3.0 (`LICENSE`). Исходный код будет опубликован при релизе; до тех пор он доступен по запросу любому, у кого есть сборка. Тексты лицензий сторонних компонентов — в архиве сборки, папка `licenses`.

---

Test builds of F4 COOP, a co-op mod for Fallout 4, for testers. Binaries only: download `F4CoopLauncher.exe` from the latest release, run it, press "Обновить" (update), then "Играть" (play). Requires Fallout 4 1.11.240 (Steam), F4SE 0.7.9 and the Address Library.

Source code will be published under GPL-3.0 at release; until then it is available on request to anyone who has a build.
